# Semi-autonomous Prosthesis Control using Multiview
Semi-autonomous control for a dexterous hand prosthesis using multiview (RGB/depth/point clouds) and sensor fusion to infer user intent, reduce cognitive burden, and assist with context-aware reaching/grasping—implemented and evaluated on functional tasks with ROS support.

## Problem
Due to the cognitive burden of controlling prostheses for amputees, the rejection rates of prostheses
usage is high. On the other hand, it is hard to realize the true intention of subjects’ movement by only
analysing myoelectric signals. One true solution is making a semi-autonomous controller that feels engaging for amputees and at the same time works smooth like a biological limb.

The aim of this project is to develop a semi-autonomous control of a dexterous hand prosthesis.

## Approach & Realisation
The project will include the following steps: 
1) an overview of the literature on the semi-autonomous
control methods and technology, 
2) selection of additional sensors and their placement on the prosthesis, 
3) development of semi-autonomous control methods based on computer vision (point cloud and/or
RGB image analysis and modeling), and 
4) assessment of the developed control using functional tasks.

The students will be able to choose the project direction and methods to be used to implement the
computer vision pipeline.
Perspectives for the students
- Understanding operation and control of a dexterous hand prosthesis
- RGB image analysis, depth sensing and point cloud processing
- Control of robotic grasping and reaching using computer vision
- Context-aware control using sensor fusion.
- Operate a prosthesis with ROS support
