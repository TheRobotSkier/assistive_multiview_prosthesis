# Make Run & Camera-Test Targets

## Objective

Add `make run` (full pipeline with EMG) and `make camera-test` (host-side proxy) targets for convenient one-shot build+launch.

## Changes Required

### 1. `Makefile.workspace` (container-side) — Add `run` target

**Option A: Replace the `camera-test` target** (lines 87-92)

Replace the existing `camera-test` block with:

```makefile
camera-test: ## Build + launch visual pipeline (no hardware)
	@$(ROS_SETUP) && \
	cd /prosthesis_ws && \
	colcon build --packages-select prosthesis_launch sensor_fusion_bringup --cmake-args -DCMAKE_BUILD_TYPE=Release && \
	ros2 launch prosthesis_launch pipeline.launch.py mia_hand:=false wrist:=false emg:=false haptic:=false mounts_config:=/prosthesis_ws/src/sensor_fusion_bringup/config/camera_mounts.yaml tf_diagnostics:=true

run: ## Build + launch full pipeline (EMG, wrist, hand enabled)
	@$(ROS_SETUP) && \
	cd /prosthesis_ws && \
	colcon build --packages-select prosthesis_launch sensor_fusion_bringup emg_bridge force_controller pipeline_manager twist_propagation --cmake-args -DCMAKE_BUILD_TYPE=Release && \
	ros2 launch prosthesis_launch pipeline.launch.py mounts_config:=/prosthesis_ws/src/sensor_fusion_bringup/config/camera_mounts.yaml tf_diagnostics:=true
```

### 2. `Makefile` (host-side) — Add proxy targets

After the `$(TONIGHT_TARGETS): dev` block (line 145), add:

```makefile
# ── Launch proxies ─────────────────────────────────────────────────────────
run: dev  ## Build + launch full pipeline (from host)
	cd $(COMPOSE_DIR) && $(COMPOSE) exec --user prosthesis prosthesis /bin/bash -lc 'make run'

camera-test: dev  ## Build + launch camera-only test (from host)
	cd $(COMPOSE_DIR) && $(COMPOSE) exec --user prosthesis prosthesis /bin/bash -lc 'make camera-test'
```

## How to Use

| Command | What It Does |
|---------|-------------|
| `make run` | Starts container, builds Python packages, launches full pipeline with EMG + wrist enabled |
| `make camera-test` | Starts container, builds, launches with hardware disabled (safe camera-only test) |
| `make shell` | Opens a shell inside the running container |
| Inside container: `make run` | Same as above but already inside |
| Inside container: `make camera-test` | Same as above but already inside |

After applying changes:
